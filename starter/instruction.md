# GitHub Copilot Instructions

When generating code for this Sudoku project:

- Follow PEP 8 Python coding standards.
- Write clean, readable, and maintainable code.
- Keep functions small and focused on one responsibility.
- Use meaningful variable and function names.
- Avoid duplicate code.
- Preserve the existing Flask application structure.
- Add comments only where they improve understanding.
- Handle invalid input gracefully.
- Ensure generated Sudoku puzzles have a unique solution.
- Keep HTML, CSS, and JavaScript organized and readable.
- Ensure the UI remains responsive.
- Write code that is easy to test with pytest.
